# CheddaBoards docs

Source for https://docs.cheddaboards.com, built with VitePress and deployed on Netlify.

```
npm install
npm run docs:dev
```

Pages are markdown under `quickstart/`, `api/`, `engines/`, `concepts/` and `self-hosting/`. Sidebar and nav live in `.vitepress/config.mts`. Add a page, then add its link to the sidebar.

Docs used to live in the CheddaBoards-Godot repo. That repo now keeps only install instructions and links here.
